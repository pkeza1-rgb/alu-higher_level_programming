# Python - Classes and Objects

This repository contains solutions for the ALU Higher Level Programming projects. The exercises introduce Object-Oriented Programming (OOP) concepts in Python, including classes, objects, attributes, methods, encapsulation, properties, and data validation.

## Learning Objectives

* Understand classes and objects in Python.
* Create and instantiate classes.
* Use private instance attributes.
* Implement getters and setters with properties.
* Validate attribute values.
* Define instance methods.
* Apply Python coding standards (PEP 8).

## Project Structure

* `python-classes/` – Solutions for the Python Classes project.
* Each task is implemented in its corresponding Python file as required by the project instructions.
