==========================
3-say_my_name
==========================

Import the function:

    >>> say_my_name = __import__("3-say_my_name").say_my_name

Print full name:

    >>> say_my_name("John", "Smith")
    My name is John Smith

Print first name only:

    >>> say_my_name("Bob")
    My name is Bob

Print empty names:

    >>> say_my_name("", "")
    My name is
